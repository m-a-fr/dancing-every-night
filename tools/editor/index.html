      Raccourcis clavier

      Pour bien commencer : le guide du créateur (étapes, conseils, formats).

      Poser

      Clic colonne : TAP
      Clic-glisser vers le haut : HOLD
      Clic-glisser vers l'autre côté : DOUBLE
      Alt+clic : double avec la lane d'en face
      Clic colonne SCRATCH : ↻ · Alt+clic : ↺

      Sélectionner

      Maj+glisser : lasso
      Maj+clic : ajouter à la sélection
      Ctrl+A : tout sélectionner
      Échap : désélectionner

      Modifier

      Glisser une note : déplacer
      Glisser le bout d'un HOLD : durée
      Clic droit / Suppr : supprimer
      D : lier / séparer une double
      R : inverser le sens des scratchs
      Ctrl+C / X / V : copier / couper / coller
      Ctrl+Z / Maj+Ctrl+Z : annuler / refaire

      Naviguer et écouter

      Espace : lecture / pause
      Molette / ↑↓ : défiler · PgUp/PgDn : mesure
      Début : revenir au début
      Ctrl+molette : zoom · [ ] : pas de la grille
      Clic forme d'onde : placer le curseur
      P : aperçu du jeu · Ctrl+S : enregistrer
